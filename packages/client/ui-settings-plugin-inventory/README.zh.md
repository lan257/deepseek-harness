# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的**插件列表**标签页，支持逐条启停控制，同时涵盖 Loader 插件与本地技能。浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献，位于配置标签页之侧；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择该标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.md) 懒调用 `ctx.remote.pluginInventory.list()`。

该标签页以可搜索的双列紧凑折叠卡片展示清单。每张收起的卡片使用模块短名称作为标题，以小标签表示有效启停状态；已启用的插件条目还会以彩色圆点表示根 fiber 状态（技能行没有 fiber，故不显示圆点）。标题下方的描述行（最多两行）优先取内置中文目录——见 `catalog.ts`，先按行 id 匹配（去掉 `include:` 树前缀，使同一包的多个行——如多个 MCP 服务器——各有自己的标题与功能描述），再按精确模块名匹配——都未命中则回退到 Host 提供的描述（MCP 行是"连接 MCP 服务器 <名称>"、技能是 SKILL.md frontmatter 描述）；鼠标悬浮被截断的描述会以原生 tooltip 显示完整文本。列表上方有一排功能分类 chips（工具、技能插件、Skill（用户技能）、MCP、界面、基础设施、其它）用于过滤——内置技能插件（`dsh-skill` 等）与用户 Skill 行是两个独立的标签，点击 **Skill** 即可单独筛出用户技能：只渲染快照中实际存在的分类，chips 多选取并集，并与搜索框组合生效。目录条目带显式分类；技能行一律归入“技能”分类，未收录的模块按名称关键词回退（mcp → skill → tool → 浏览器侧），仍无法区分的一律归入“其它”。展开插件卡片后会直接展示 Loader 树条目 id，不附加重复的字段标题，并列出有效配置状态；已启用的条目还会列出 Cordis 状态；技能卡片则展示其 SKILL.md 路径，而非配置状态或 Cordis 状态。已停用的条目省略重复的“未挂载”运行状态。条目 id 仍作为 React key、展开标识、详情值与额外的搜索目标；代码不按字符串形状对它分类。搜索会匹配模块名、Loader 条目 id 与展示的描述（含中文目录文本）。加载、空结果、无匹配结果与通用失败状态只属于已挂载组件；读取失败后可以重试，且不会暴露传输细节。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

每张展开的卡片还带一个启停操作：已启用的条目提供**停用**，已停用的条目提供**启用**。点击后调用 `ctx.remote.pluginInventory.setEnabled(entryId, 目标状态)`；请求进行中时操作按钮被禁用并显示“应用中…”，调用失败时把 Loader 的错误就地展示出来。成功后标签页重新读取快照，卡片随即反映新的有效启停状态与 fiber 阶段。该操作只是 Host Remote 之上的客户端便利层——它自己不会重排或分类条目。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每次 Settings 挂载或重试只读取一份快照** —— 标签页不订阅 Loader 变化，也不会在重连后自动重新读取；切换标签页会保留当前快照，重新打开 Settings 则会取得新快照。
- **仅支持启停** —— 标签页只能切换既有条目的启用状态，不能添加、移除或重新配置插件行；逐条启停写入字面值，会覆盖该条目原有的 `!!js` disabled 表达式。
